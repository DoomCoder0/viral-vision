# Viral Vision

Web stranica digitalne agencije Viral Vision.

## Objavljivanje

Pripremljen lokalni ZIP s izvornim kodom. U GitHub repozitorij potrebno je učitati **sadržaj mape** `Viral-Vision-Publish-Ready` iz ZIP-a (ne samu mapu). Izostaviti `.env` i direktorij `data` sa stvarnim korisničkim podacima.

Za Render: runtime Node.js 22+, build command `npm install`, start command `npm start`.

Prije javne objave obrazac za kontakt treba povezati s trajnom bazom; besplatni Render servis nema zajamčenu trajnu pohranu SQLite baze.
